# Prompts de imagem — cursos novos (lista 2026)

São os **45 cursos que ainda não têm foto**. Use o mesmo **estilo base** do arquivo
`prompts-imagens-cursos.md` (cole o estilo base e, logo depois, o prompt do curso).

## Como usar

1. Gere na mesma ferramenta das fotos anteriores, em **3:2 horizontal** (ex.: 1536 × 1024).
2. Salve cada imagem com o nome indicado, em **`assets/img/_originais/`**
   (PNG, JPG ou WEBP). Ex.: `assets/img/_originais/tecnico-em-mecanica.png`
3. Na pasta do projeto, rode:
   ```
   python scripts/processar-imagens.py
   node scripts/gerar-lps.js
   ```
   O primeiro cria as versões otimizadas (`.webp` da página e `-card.webp` do card);
   o segundo coloca as fotos nas páginas.
4. Descarte imagens com texto, logotipos, mãos ou rostos deformados, ou equipamentos que não fazem sentido.
